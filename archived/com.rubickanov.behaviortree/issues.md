## Critical (correctness / bugs)

- **Play-mode runtime state visualization is dead — GUID regeneration on Clone breaks the lookup** — `Editor/BehaviorTreeGraphView.cs:552` / `Runtime/Core/BTNode.cs:63`. `BehaviorTreeEditorWindow.Update()` feeds `_cachedRunner.RuntimeRoot` into `UpdateRuntimeState`, which builds `_runtimeStateMap` keyed by each **runtime** node's `Guid` (`CollectRuntimeStates` at line 563) and then matches it against each `nodeView.Guid` (line 552), where node views are keyed by the **asset/serialized** GUID (`BehaviorTreeNodeView.cs:27`). But the runtime tree is produced by `BehaviorTreeAsset.CreateInstance()` → `BTNode.Clone()`, which assigns a fresh GUID to every node (`clone._guid = System.Guid.NewGuid().ToString();`, line 63 — and the test `CreateInstance_GeneratesFreshGuidsForEveryNode` enshrines this). Therefore the runtime GUIDs can never equal the node-view GUIDs, `stateMap.TryGetValue(nodeView.Guid, ...)` always misses, and every node falls through to `ClearState()`. The running/success/failure highlighting in the editor never appears. Fix: make the runtime `Clone()` path preserve `_guid` (the editor copy/paste path already has its own `ShallowClone()` that legitimately regenerates GUIDs for distinct pasted nodes), or remap runtime nodes to asset GUIDs structurally before lookup.

## Minor (conventions / shortcomings)

- **BTSubtree category is inconsistent across attribute, README, and actual type** — `Runtime/Nodes/Decorators/BTSubtree.cs:7` / `README.md:167`. `BTSubtree` lives in the `Nodes/Decorators/` folder, is documented under the **Decorators** table in the README, but its `[BTNodeDescription("Subtree", "Composites", ...)]` puts it in the **Composites** group of the editor search window (`BehaviorTreeSearchWindow.BuildSearchTree` groups by `attr.Category`). It is in fact none of the three — it derives directly from `BTNode`, not `BTComposite` or `BTDecorator`, and `GetNodeCategory` special-cases it as `NodeCategory.Subtree`. Additionally, because `CollectNodesRecursive` uses `attr.Category` as the node's on-graph description text (`BehaviorTreeSerializer.cs:146`), a Subtree node with no asset assigned displays the literal string "Composites" as its description. Pick one consistent category and align the attribute, the README, and the description fallback.
