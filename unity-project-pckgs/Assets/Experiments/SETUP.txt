ACS Netcode Experiment — Setup
================================

1. PREFAB: "ExperimentEntity"
   Create a new prefab with these components on the root:
   - EntityContext
   - NetworkObject
   - AspectReplicator
   - ServerLogic
   - ExperimentInputProvider  (owner-only; reads WASD → ExperimentInputCommand)
   - ExperimentMover          (ISimulate; writes Position on both owner + server)
   - ExperimentHUD
   Add a visible mesh (Cube/Sphere) so you can see the entity.

   The provider/mover split means one prefab covers every mode. Edit
   `ExperimentAspect.Position` attributes to flip between:
     - `Authority = Server` + `[Predicted]`
         → prediction + reconcile (clean local view)
     - `Authority = Server` (no `[Predicted]`)
         → owner sends input, server Simulates, broadcast; owner's local
           Simulate still runs and snaps back each broadcast
     - `Authority = Owner` (± `[Predicted]`)
         → owner's Simulate is the authoritative write, relayed to peers;
           `[Predicted]` is a no-op here
   The pipeline bootstraps whenever `ISimulate<T>` is present — `[Predicted]`
   only controls whether snapshot capture + reconcile run on top of it.

2. SCENE: "ExperimentScene"
   - NetworkManager (UnityTransport, tick rate ~30)
     → set Player Prefab = ExperimentEntity
     → add ExperimentEntity to Network Prefabs list
   - Empty GameObject with NetworkExperimentBootstrap
   - Camera (e.g. pos 0,10,-10, look at origin)
   - Directional Light

3. RUN
   - Play → click "Host"
   - Entity auto-spawns for host player
   - WASD moves it (owner-auth Position)
   - Server rotates it (server-auth Rotation)
   - Damage every 3s (Health drops + DamageDealt event fires)

4. MULTIPLAYER PLAY MODE (second client)
   - Window → Multiplayer → Multiplayer Play Mode
   - Add a virtual player, set to "Client"
   - Enter play mode — both peers see each other's entities
   - Watch interpolation on remote entities

5. Tab hides/shows the connection panel.
