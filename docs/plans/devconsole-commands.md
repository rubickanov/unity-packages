# Dev Console: доработка встроенных команд

План по разбору встроенных команд `com.rubickanov.devconsole` (2026-09-25). Идём строго по порядку,
отмечаем `[x]` когда пункт сделан и проверен.

## Баги и ядро

- [x] **1. Бинды загружаются при старте.** Сейчас `CommandBindings` создаётся только командой `bind`, поэтому
  сохранённые бинды не работают в новой сессии, пока не забиндишь что-то новое.
- [x] **2. Аргумент «остаток строки».** Атрибут `[Remainder]` на последнем `string`-параметре: он получает весь хвост
  исходной строки как есть, с кавычками. Применить к `bind`, `alias`, `repeat`, `echo` — `bind F5 timescale 0.5`
  без кавычек.
- [x] **3. Ошибка на лишние аргументы.** Сейчас лишние токены молча выбрасываются.
- [x] **4. `Nullable<T>` в аргументах.** `int? value = null` вместо заглушек `-1`/`-2`/`(FullScreenMode)(-1)`; usage
  показывает `[value]`. Переписать `target_fps`, `vsync`, `timescale`, `resolution`, `fullscreen`, `log_unity`
  (без аргумента — показать состояние).
- [x] **5. Результат бинда виден.** Ошибка или вывод забинженной команды пишется в консоль.

## Alias

- [x] **6. Раскрытие без потери кавычек.** Хвост после имени алиаса подставляется сырым, `myalias "a b"` остаётся
  одним аргументом.
- [x] **7. Несколько команд через `;`.** `alias reset "timescale 1; clear"`, работает везде: в консоли, биндах,
  `exec`, `-command`. `;` внутри кавычек не делит строку.
- [x] **8. Параметры `$1..$9` и `$*`.** `alias tp "teleport $1 $2"`; без `$` хвост дописывается в конец, как сейчас.
- [x] **9. Проверка имени.** Без пробелов и кавычек, нельзя назвать алиас именем существующей команды.
- [x] **10. Алиасы в автодополнении и `help`.**

## Bind

- [x] **11. Автодополнение клавиш.** Имена `Key` подсказываются.
- [x] **12. Модификаторы.** `ctrl+F5`, `shift+alt+K`.
- [x] **13. Предупреждение при бинде на клавишу открытия консоли.**
- [x] **14. Не срабатывать при вводе текста в игре.** Хук `CommandBindings.Suppress` (`Func<bool>`), игра сообщает,
  что фокус в своём текстовом поле.

## Структура и хранение

- [x] **15. Группы подкоманд вместо «режимов по числу аргументов».** `alias list|set|rm|clear`,
  `bind list|set|rm|clear`, `history list|clear`. Убрать `unalias`, `unbind`, `alias_clear`, `binding_clear`,
  `history_clear` и описания «no args=list, 1 arg=show…».
- [x] **16. Бинды и алиасы в `config.cfg`.** `persistentDataPath/console/config.cfg` строками `bind set F5 "…"`,
  перезаписывается при изменении и выполняется при старте, плюс необязательный `autoexec.cfg`. Одноразовый перенос
  из PlayerPrefs.
- [x] **17. `exec`: защита от рекурсии, Android, расширение.** Ограничение глубины вложенных `exec`, чтение
  StreamingAssets на Android через `UnityWebRequest`, понятная ошибка на WebGL, `exec autoexec` находит
  `autoexec.cfg`.

## Остальные команды

- [x] **18. `help`.** `help <категория>` и `help <подстрока>` по имени и описанию; ошибка вместо полного списка,
  если ничего не нашлось.
- [x] **19. `history list [N]`.** Последние N записей вместо всех 100.
- [x] **20. `repeat`: лимит.** Не больше 1000 повторов.
- [x] **21. `fps`: среднее за секунду.** Среднее, минимум и максимум вместо одного кадра.
- [x] **22. `timescale` в категорию Time, команда `pause`.** `pause` ставит 0 и возвращает прежнее значение.
- [x] **23. `vsync`.** Сообщать об обрезке до 0..4 и о том, что vsync перекрывает `target_fps`.
- [x] **24. `version` + `sysinfo` → одна `sysinfo`.**
- [x] **25. Сцены.** `scene` без `Dirty` вне редактора; `scene_load <имя|индекс>` с автодополнением по сценам билда;
  `scene_reload`.
- [x] **26. `find` + `inspect` → одна `inspect`.** Все совпадения, включая неактивные, путь и компоненты.
- [x] **27. `count`: флаг неактивных.**
- [x] **28. `resolution_list`.** Отдельной командой, как `scene_list`: у `resolution` первый аргумент — число.

## Новое

- [x] **29. `toggle <команда> <a> <b>`.** Чередует два значения, удобно на бинд: `bind set F1 toggle timescale 0 1`.
- [x] **30. `wait <кадры>`.** Пауза внутри `;`-цепочки и `exec`, остаток выполняется позже.
