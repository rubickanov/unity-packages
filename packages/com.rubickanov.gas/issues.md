## Critical (correctness / bugs)

- **[FIXED]** Reentrant `ApplyEffect`/`RemoveEffect` from a `GameplayAttribute.ValueChanged` handler throws — `Runtime/Effects/EffectController.cs:302` (`RecalculateAttributes`) + shared `_dirtyAttributes` at `:12`. `ApplyEffect`, `RemoveEffect`, and `RemoveEffectsWithTag` recalculate via `RecalculateAttributes(_dirtyAttributes)`, which does `foreach (var tag in tags)` over the single shared `_dirtyAttributes` HashSet. Inside that loop `RecalculateAttribute` → `attribute.SetCurrentValue` fires `GameplayAttribute.ValueChanged` (`Runtime/Attributes/GameplayAttribute.cs:39`). If a `ValueChanged` handler reentrantly calls `ApplyEffect`/`RemoveEffect`/`RemoveEffectsWithTag`, that reentrant call executes `_dirtyAttributes.Clear()` (e.g. `EffectController.cs:45`, `:114`, `:133`) while the outer `foreach` is still enumerating it, so the next `MoveNext()` throws `InvalidOperationException: Collection was modified`. This is a realistic pattern ("when shield/health drops, apply a counter-effect"). The controller deliberately makes its own `EffectApplied`/`EffectRemoved` events reentrancy-safe (snapshot-then-clear in `FireRemovedBatch`), but the attribute-value callback path is not protected. Fix: snapshot the dirty tags into a local array/pooled list before iterating, or use a per-call buffer instead of the shared instance field.

## Minor (conventions / shortcomings)

- **[FIXED]** `EffectController` never unsubscribes from `AttributeSet.BaseValueChanged` — `Runtime/Effects/EffectController.cs:36`. The constructor does `_attributes.BaseValueChanged += OnBaseValueChanged;` but the class exposes no `Dispose`/teardown and never detaches the handler. If a new `EffectController` is created for an `AttributeSet` that outlives the old one (re-init, pooling, respawn reusing the same attribute set), the stale controller stays subscribed and keeps recalculating against its now-empty/dead effect list, and is kept alive by the event reference (leak). Fix: implement `IDisposable` (or an explicit `Detach`) that removes the handler.
