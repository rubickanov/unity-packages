# Audit findings — com.rubickanov.devconsole
Generated by automated review.

## Critical (correctness / bugs)

- **`Keyboard.current` null-deref in built-in toggle** — `Runtime/UI/DevConsoleUIToolkit.cs:146` — `if (settings.UseBuiltInToggle && Keyboard.current[settings.ToggleKey].wasPressedThisFrame)` indexes `Keyboard.current` without a null check, and this runs every frame in `Update`. `Keyboard.current` is `null` on sessions/platforms with no keyboard (mobile, gamepad-only, or during the first frames before Input System initialization), so this throws a `NullReferenceException` every frame. The sibling `CommandBindings.Update` (line 56) explicitly guards with `if (Keyboard.current == null) return;`, confirming the author is aware of this hazard — the guard is just missing here. Fix: bail out when `Keyboard.current == null` before reading the indexer.

- **Collection modified during enumeration in key bindings** — `Runtime/Core/CommandBindings.cs:62-66` — `Update` does `foreach (var kvp in _bindings) { ... CommandRegistry.Instance.Execute(kvp.Value); }`. A bound command that mutates `_bindings` — e.g. `bind F1 binding_clear`, `bind F1 "unbind f2"`, or any `bind`/`unbind` — calls `Dictionary.Clear`/`Remove`/`Add` while the dictionary is being enumerated, throwing `InvalidOperationException` out of `Update`. Binding a console command to a key is exactly the intended use case, so this is reachable with normal input. Fix: snapshot the keys/pairs (or collect commands to run into a reused list) before executing.

## Minor (conventions / shortcomings)

- **IMGUI frontend ignores `DevConsoleSettings`** — `Runtime/UI/DevConsoleIMGUI.cs:11,111` — `DevConsoleIMGUI` hardcodes `ConsoleHeightRatio = 0.5f` and the BackQuote toggle key, and never reads `DevConsoleSettings` (`UseBuiltInToggle`, `ToggleKey`, `ConsoleHeight`). The README "Settings" section (README.md:288-293) presents Toggle Key / Use Built-in Toggle / Console Height as console-wide options and Quick Start offers IMGUI as an interchangeable alternative to the UI Toolkit frontend, so a user choosing IMGUI will find none of these settings take effect and cannot disable the backquote toggle. Either honor the settings in the IMGUI frontend or document that those settings apply only to `DevConsoleUIToolkit`.
