## Minor (conventions / shortcomings)

- **Floats are persisted with the default numeric format, risking precision loss** — `Runtime/FileStorageService.cs:59` (and `Runtime/EncryptedStorageService.cs:54`) — `value.ToString(CultureInfo.InvariantCulture)` uses the default ("G") format. This is not guaranteed to be the shortest round-trippable representation on every runtime/Unity-Mono version, so a value written and re-read can differ in the low bits. For a persistence layer this is a data-integrity footgun. The existing round-trip test only uses `0.75f`, which is exactly representable and round-trips under any format, so the test does not actually guard against this. Use the round-trip format specifier (`value.ToString("R", CultureInfo.InvariantCulture)`) when serializing floats.

- **README Assemblies table omits `PrefixedStorageService`** — `README.md:24` — the Architecture diagram (lines 11-18) correctly lists `PrefixedStorageService` under `Storage.Runtime`, but the Assemblies table's Storage.Runtime description enumerates only "Interface, FileStorageService, EncryptedStorageService, NullStorageService". `PrefixedStorageService` is a public Runtime type and should be listed for consistency.
